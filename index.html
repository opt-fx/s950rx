Record through the sampler

Plays a file into the sampler's own input, so it carries the machine's 12-bit sound. The sampler cannot be set up over MIDI, so the app works out the settings and, on a V1.0A or V1.2A sampler, types them in for you. Cable the computer's audio output to the sampler LINE input first.

Record the whole queue one take after another

For each file the app types the name, bandwidth and time, counts down, then plays it. Set the level once on the first take. For every take you press ENT on the sampler during the countdown, because the sampler will not take ENT from the app. Each new sample is found, named and pitched automatically.

    The sampler has Omni on (MIDI page 1), so it plays notes on every MIDI channel. Keygroup channels only take effect with Omni off.
    The program on the sampler has changed since you loaded it (turning the dial, perhaps), so updating would overwrite those changes.
    Over RS232 it will go through. The app can switch the sampler to RS232, send it, then switch back to MIDI (needs the USB serial adapter plugged in).

    Keys can be note names (C3, F#4) or MIDI numbers 0–127; middle C is C3 = 60. Overlapping ranges layer. Shift-click a checkbox, or shift-choose from a drop-down, to set it on every row.
    Changed something on the sampler's own dial? Press Load from sampler to bring it in; the app warns before overwriting.
